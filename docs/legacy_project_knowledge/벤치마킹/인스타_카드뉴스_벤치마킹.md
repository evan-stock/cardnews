초반 조회수가 안 나오다가 아래 게시물들로 떴다. 계정 정체성은 다양한 화제(트렌드·도파민·매거진)이고, 이런 소재는 **유입용으로 섞는** 것.

**표지 3줄 공식**
1. 1줄 = 감정 프레임: 속마음 인용("내 세금 여기에...", "한국인은 안되는데..") 또는 긴박감('대형 사고 1분전')
2. 2줄 = 누가/무엇이(수급자, 중국인 89억, KTX 선로 위 돌덩이)
3. 3줄 = 숫자·반전 결말 단정형(연봉 4,800 찍었다, 범인은 10대 고등학생)

**그 밖의 특징**
- 공유가 좋아요의 1~6배. "이거 봐" 하고 단톡방에 보내는 소재.
- 장 수가 적다(1~2장). 표지 한 장에 이야기가 다 있음. 설명은 본문.
- 증거 이미지(급여 내역 캡처 등)를 빨간 테두리 박스로 표지에 겹쳐 신뢰감·분노 강화.
- 사진이 없으면 연출(스톡) 사진도 씀.
- 음악 항상 있음.
- 본문: 🚨 + 한 줄 훅 → 이모지 소제목 + 짧은 문단(날짜·장소·숫자).

## 오늘의쓸모 적용
- 비중: 다양한 화제(해외 황당·인물 사연, 셀럽, 반전 서사) 위주 + **분노·경각심 유입용 주 2~3개**. 분노 대상은 제도·특혜·불공정(집단 비하 금지).
- 표지: 3줄 공식(감정 프레임 → 대상 → 숫자·반전 결말). 증거 캡처는 PIL로 빨간 박스 합성해서 표지에 삽입.
- 분노형은 2~4장으로 짧게, 정보는 본문에.
- 연출 사진을 쓰면 본문에 "참고 이미지" 표기.
- 음악은 게시 후 앱에서 추가.
