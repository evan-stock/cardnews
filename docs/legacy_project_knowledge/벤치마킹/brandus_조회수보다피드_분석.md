## 핵심 주장 (요약)
- 사례: 게시물 1개 6.8만 조회 → 프로필 방문 991 → 팔로우 116. 방문자 875명이 그냥 나감.
- 릴스를 고쳐도(훅·편집·음원) 팔로워가 안 느는 건 릴스 문제가 아니라 **피드(프로필 9칸)** 문제.
- 릴스 본 사람은 바로 팔로우하지 않고 프로필 9칸을 훑는다. '결이 같으면 팔로우, 다르면 뒤로가기'가 3초 안에 결정.
- 같은 '꿀팁'이어도 편집 꿀팁 / 살림 꿀팁 / 여행 꿀팁은 다른 사람을 부른다 → 엉뚱한 주제로 들어온 사람은 "내 계정 아니네" 하고 나감.
- 작성자 사례: 팔로워 1만 됐을 때 게시물은 9개뿐 → 9칸이 전부였다.
- 피드에서 붙잡는 건 '톤앤매너': 톤=말투(친구처럼 말하다 "안내드립니다"로 바뀌면 낯섦), 매너=분위기(얼굴 보며 말하다 갑자기 광고 영상 → 다른 사람 같음).
- 성적표 분리: 릴스 한 편 = 조회·좋아요·저장(발견) / 피드 전체 = 프로필 방문 대비 팔로우(머무르게 하기).
- 피드 편집 3기준: ① 9칸 첫인상은 가장 자신 있는 주제로만 ② 주제가 다른 게시물은 보관 ③ 통일감은 색감보다 '한 줄(주제)'이 먼저.
- 한 줄 결론: 조회수는 데려온 사람 수, 팔로워는 머문 사람 수.
