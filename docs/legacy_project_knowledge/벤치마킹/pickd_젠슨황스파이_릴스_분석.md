## 고퀄로 보이는 이유
- 제목을 끝까지 고정해서 중간에 들어와도 무슨 얘긴지 바로 앎
- 실사 사진은 그대로 쓰지 않고 **빨간 원·라벨·감시 프레임·지도·숫자** 같은 그래픽을 위에 얹어 "취재한 느낌"을 줌
- 하단 자막은 매 컷 "작은 맥락줄 + 2줄 결론"으로 똑같은 틀 → 통일감
- 컷마다 줌인·페이드·카운트업 같은 작은 움직임
- 자막 끝맺음을 계속 반전/떡밥형으로(누구? → 임원 → 의혹 → 포착 → 침묵 → 훈장)
