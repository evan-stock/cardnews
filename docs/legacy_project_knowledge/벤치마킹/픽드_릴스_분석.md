### 왜 픽드는 팔로우로 이어지나 (추정)
1. **계정이 한 줄로 설명된다.** 소개 "뉴스보다 빠른 이슈, 픽드가 제일 먼저" + 피드 30개가 전부 같은 결(정치·안보 속보). 프로필에 들어온 사람이 "이 계정 = ○○" 를 1초 만에 안다. 오쓸은 프로필에 들어가면 상어·코끼리·마크롱·북한이 섞여 있어 "따라가면 뭘 받지?"가 흐리다.
2. **진행 중인 이야기를 연달아 낸다.** 선관위 특검 하나로 하루에 4~5개(검증 현장, 촬영 불허, 벽돌 투표지, 새벽 반출), 북한도 4~5개. 릴스 하나 보고 프로필에 들어가면 같은 이야기의 다음 편이 줄줄이 있다 → "다음 소식 받으려면 팔로우". 오쓸 '후속편 약속장부'와 같은 원리인데 픽드는 훨씬 촘촘하다.
3. **편이 같은 사람끼리 모인다.** 댓글에서 같은 편끼리 공감(댓글 좋아요 수천) → "내 편 계정"이라 팔로우. 소속감 팔로우.
4. **릴스는 화면에 팔로우 버튼이 바로 있다.** 캐러셀은 프로필까지 들어가야 하고, 오쓸은 프로필 방문 239 → 팔로우 22(약 9%)에서 한 번 더 걸러진다.

### 오쓸에 적용
- **프로필 첫 화면을 약속으로 만든다**: 소개 첫 줄에 "팔로우하면 매일 받는 것"을 한 줄로. 고정 게시물 3개를 계정 성격을 가장 잘 보여 주는 시리즈(예: 전쟁 징후, 유럽 시위)로.
- **터진 소재는 그날 안에 후속을 2~3개 더**: 터진 게시물에서 프로필로 넘어온 사람이 같은 이야기의 다음 편을 보게.
- **릴스 비중을 늘린다**: 팔로우 버튼이 화면에 있는 형식에서 승부.
- 프로필 방문 → 팔로우 비율을 게시물마다 성과 기록에 같이 적어 비교한다.

2. **제목은 모순·말 인용형**: "공개검증 한다더니 '촬영 안 된다'", "대통령이 간첩을 팔로우?" 듣는 순간 한마디가 나오는 문장(시그널 분석과 같은 결론).
3. **댓글 전쟁이 확산 엔진**: 상위 댓글 좋아요가 수천(6,840·4,278). 끝 질문이 편 가르기형이라 댓글이 많이 달림.

5. **카드형 캐러셀은 버리고 릴스로 승부**: 같은 날 같은 소재여도 피드는 수십, 릴스는 수십만.
