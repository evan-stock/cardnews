## 애니메이션 포인트 (왜 고퀄로 보이나)
1. **지도 1장 + 누적**: 장면마다 새 그림을 만들지 않고, 같은 지도에 핀이 하나씩 쌓임 → 마지막에 "이만큼 쌓였다"는 결론이 시각적으로 완성됨
2. **핀 → 점선 → 사진 카드**: 장소 핀에서 점선이 뻗어 사진 카드에 연결 → 지도와 실사를 한 화면에 묶음
3. **색 의미 고정**: 북한 관련 = 빨강, 미국·우리 쪽 = 초록. 하단 강조 자막도 초록
4. **미사일 궤적**: 빨간 곡선 여러 개가 퍼지는 장면 하나가 긴장감의 정점
5. **오프닝 전환**: 실사 → 지도 크로스 디졸브(약 0.4초), 자막도 같은 타이밍에 교체
6. 하단 맥락줄을 "징후 N · 출처"로 번호 매김 → 6개 다 볼 때까지 이탈 막음

## 오늘의쓸모로 만들 때
- 지도 SVG(국가 경계) 1장 + 장면 목록 JSON(핀 좌표, 이름, 사진, 자막 2줄, 출처) → HTML/CSS 애니메이션으로 렌더 → 프레임 캡처 후 ffmpeg로 mp4 (→ `scripts/map_reel/`로 구현 완료)
- 장면 수 5~7개, 장면당 약 3초, 끝에 "완성 지도 + 질문형 결론" 1장면
- 응용: 나라별 시위 확산(유럽 시위), 태풍·지진 경로, 매장 철수 지도 등 "장소가 여러 개인 뉴스"에 전부 쓸 수 있음
- 우리 버전은 노랑 핀·노란 윤곽(pickd의 빨강·초록과 구분), today.worthy 로고, 합성 효과음(핀 '퉁'·카드 '팝'·전환 '휙'·정리 '쿵'·끝 '띵'·심장박동)
