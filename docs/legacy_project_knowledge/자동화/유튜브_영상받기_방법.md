# 유튜브 영상 받기 (2026-11-05 확인)

- GitHub 서버(fetch-video)와 클라우드 작업공간에서는 유튜브가 "봇 확인"으로 막는다.
- **된 방법:** 맥북 연결 → 사용자 허락을 받아 `~/Movies` 폴더 접근 요청(device_request_folder_access) → device_bash에서 `python3 -m yt_dlp -f "bv*[height<=1080]+ba/b" --merge-output-format mp4 --write-info-json -o v1.%(ext)s <주소>` (맥북 네트워크라 바로 받아짐) → device_stage_files로 가져와 `media/<id>/video/v1.mp4` + `v1.json`(제목·채널·날짜) 커밋.
- 폴더 접근은 사용자가 채팅에서 "써도 돼"라고 직접 허락해야 진행된다.
- 첫 사례: 20261105-yt1 (YTN 트럼프 '거래 외교' 긴장, 1280x720, 2:31)
