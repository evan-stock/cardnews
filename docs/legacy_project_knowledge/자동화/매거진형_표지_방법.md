# 매거진형 표지 방법 (2026.10.29)

매번 쓰는 게 아니라, 필요할 때 꺼내 쓰는 표지 옵션입니다. 실제 사진이 약하거나(저화질·밋밋함), 인물 얼굴 하나로 승부하거나, 숫자가 핵심인 소재일 때 씁니다. 미리보기 때 일반 표지와 매거진형 2~3종을 나란히 보여주고 고릅니다.

- 도구: 저장소 `scripts/mag_cover.py` (7가지 스타일)
- 자세한 사용법: 저장소 `docs/skill_today-worthy-cardnews-v6.md`의 '매거진형 표지' 절
- 첫 사용: 20261029-warsigns(전쟁 징후 17개) — 레드 듀오톤 + 김정은 + 노란 '17 WAR SIGNALS' 채택

| 스타일 | 모습 | 어울리는 소재 |
|---|---|---|
| duotone | 사진 전체를 한 색(빨강 등)으로 + 대형 숫자 | 경보·위기·분노 (채택) |
| cutout | 누끼 인물 + 뒤에 초대형 숫자, 머리가 숫자를 가림 | 인물 한 명이 주인공 |
| frame | 굵은 노랑 테두리 | 시리즈물, 격자 통일 |
| bignum | 위 흑백 사진 + 초대형 숫자 + 두 줄 | 숫자가 곧 결론 |
| halftone | 신문 망점 + 노란 형광펜 태그 | 저화질 사진 살리기, 레트로 |
| symbol | 검정 바탕에 상징물 하나 | 사람 없이 분위기, 차분·고급 |
| split | 위 인물 / 아래 사건 장면 | 인물과 사건 대비 |

## 같이 정한 것
- 원본은 세로·고화질 정면 사진(위키백과 인물 문서가 고화질 초상을 잘 줌). 워터마크는 잘라냄.
- 체크리스트형은 결론을 앞에서 깔지 않음: 2장엔 목록만, 판정판은 결론 장에서 공개.
- 이모지 체크(✅△)는 쓰지 않음. 소제목은 글자로.
