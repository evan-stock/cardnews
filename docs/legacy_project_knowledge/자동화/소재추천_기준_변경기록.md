## 2026.11.01 (밤) — 국내 이슈는 당일 안에·다르게, 불안+반전 있는 국내 소문은 작아도 넣음

## 2026.10.21 — '뭐 어쩌라고?' 소재는 탈락 (해외 화제도가 커도)
- **계기:** 10.20 오후 추천 1순위였던 '스파이더맨 대학생 300만 달러 필드골'(ESPN 칼리지 게임데이, 해외 화제도 큼)을 릴스로 만들었으나 사용자가 기각. 사용자 평가: "한국 정서로는 이게 무슨 행사인지, 뭔 감성인지 모르겠다." 이어서 보충: "무슨 상황인지 아나?라기보단 **딱 봤을 때 '뭐 어쩌라고?'** 이런 느낌."
- **결정(사용자):** 문제는 상황 이해가 아니라 **보는 사람과 아무 상관이 없어 감정이 안 걸리는 것**이다. 남의 나라 행사에서 남이 돈 번 이야기처럼, 보고 나서 "그래서 뭐?"가 되는 소재는 해외 화제도가 커도 탈락.
- **판단 질문:** "한국 사람이 이걸 보고 '헉 / ㅋㅋ / 울컥' 하나, 아니면 '그래서 뭐?' 하나?"
- **세부:**
  - 남이 상금·행운을 얻은 이야기, 현지 스포츠 이벤트·방송 이벤트, 현지 응원 문화는 대체로 '뭐 어쩌라고?'에 걸린다
  - 통하는 쪽: 몸이 먼저 반응하는 장면(상어가 바로 뒤에서 솟구침 같은 소름), 누구나 겪는 상황의 공감·웃음, 불공정에 대한 분노, 울컥하는 순간
  - '와' 영상이라도 '와' 다음에 감정이 이어지지 않으면 1순위로 올리지 않는다
- **반영 위치:** 이 기록, 저장소 docs 스킬 파일의 사용자 피드백 목록, 예약 작업 지시문.

## 2026.10.19 — '해외 화제도' 표시 필수, '큼' 없으면 TOP 3 억지로 안 채움
- **계기:** 10.19 오후 추천의 TOP 3(범고래 참고래 사냥·스케이트보드 151km·AI 장난감 로봇)가 모두 '한국 미전파'였지만, 해외에서 크게 터졌다는 근거(조회·업보트·리포스트)는 없었음. Reddit이 차단돼 '해외 언론이 다뤘는지'로 대신 판단했고, 그 결과 지역 뉴스·홍보성 기사 수준 소재가 섞임. 사용자 지적: "한국 미전파인 건 좋은데 해외에서 이슈가 됐던 건가?"
- **결정(사용자 동의):**
  - 소재마다 **해외 화제도: 큼 / 보통 / 작음** + 근거 한 줄(본 조회·업보트·리포스트 수, 다룬 나라·매체 수)을 적는다.
    - 큼: 조회 수백만 이상, Reddit 인기글 상위, X 트렌드 등 수치로 확인되거나, 여러 나라 주요 매체(AP·BBC·CNN·데일리메일 등)가 '바이럴'로 보도 (→ 10.23부터 Reddit·X 대신 매거진 인스타 계정 수치)
    - 보통: 여러 나라 매체가 보도했지만 수치 없음, 또는 기업·기관 홍보성 확산
    - 작음: 지역 매체 1~3곳, 업체·기관 발표 1곳
  - '미전파'라도 해외 화제도 '작음'이면 1순위 불가. TOP 3는 '큼'을 우선하고, '큼'이 하나도 없으면 억지로 채우지 않고 "오늘은 해외에서 크게 터진 소재를 못 찾았다"고 밝힌다.
  - 홍보성 확산(기업 공식 발표·협찬 기록 등)은 근거에 '홍보성'이라고 표시한다.
  - Reddit·X를 못 열었으면 화제도 판단이 약하다는 점을 맨 위에 밝힌다. (→ 10.23부터 인스타 계정을 못 열었을 때로 바뀜)
