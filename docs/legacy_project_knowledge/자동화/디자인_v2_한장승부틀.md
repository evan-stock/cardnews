# 디자인 v2 '한 장 승부 틀' (2026.10.20 확정)

참고 계정: @signal__news (사진 한 장 + 얇은 1줄·굵은 1줄 + 하단 중앙 로고). 목표: 글씨체·딱지가 제각각이던 피드 통일.

## 캐러셀
- 원고 표지 장에 `"lay":"one"` → 표지·본문·CTA 모두 새 틀. 빼면 옛 틀.
- 표지: 사진 꽉 + 아래 어둡게, 가운데 정렬. 1줄 얇게(Pretendard Medium) 배경 설명, 2줄 굵게(Pretendard Black) 결과. 노란 '강조' 유지. 위쪽 ● TODAY.WORTHY 딱지 없음.
- 빨간 동그라미 쓰지 않음(사용자 지시).
- 본문 장: 왼쪽 정렬·작은 글씨. 노란 소제목 → 굵은 제목 → 본문(2~3줄 이내). 가운데 정렬은 "bal":"center".
- CTA: 표지 사진 흐리게 + 굵은 문구 + 얇은 한 줄 + 외곽선 '＋ 팔로우 @today.worthy' + 하단 로고.
- 로고: today.worthy (brand/logo_typo_A.png, config brand.logo). 프로필 사진 brand/profile_today_worthy.png.

## 브랜드·기업 소재 표지 = 브랜드 로고 넣기 (2026.10.24 사용자 지시)
- 에어비앤비·애플·맥도날드처럼 특정 브랜드·회사 이야기면 **표지 사진 위에 그 브랜드 로고를 원형으로 크게** 넣는다(표지·릴스 커버 모두).
- 이유: 스크롤 중 0.5초 안에 "아 에어비앤비 얘기구나"가 보여야 멈춘다. 사진만으론 무슨 회사 얘기인지 모름.
- 참고: @bokduk.gallery 에어비앤비 게시물 — 실사 사진(체크아웃하며 이불 정리) 왼쪽 위에 흰 테두리 원 + 에어비앤비 로고. 같은 소재로 우리(로고 없음, AI 사진)는 조회 293.
- 사진은 그 상황 그대로의 평범한 실사. 연출 티 나는 AI 사진은 피한다.
- 위 '빨간 동그라미 금지'와는 다른 것(그건 강조 표시용 빨간 원).

## 릴스
- 원래 양식 유지(왼쪽 정렬, 굵은 제목 줄당 10자, 마지막 줄 노랑, 크기 동일). 마지막 줄 기준선 y=1675 고정(2줄 제목이 위로 뜨던 문제 수정).
- 바뀐 것: ● TODAY.WORTHY 글자 → today.worthy 로고(제목 위), 제목 Pretendard Black.
- 도구: scripts/reel_overlay.py

## 격자·릴스 분리 운용 (2026.10.20 사용자 결정)
- 프로필 격자 = 캐러셀만, 릴스 = 릴스 탭에만(config reels.share_to_feed: false). 격자가 릴스 커버의 가운데 3:4만 보여서 릴스 제목 끝줄이 잘리기 때문.
- 고정 게시물은 잘 된 캐러셀로(예: 마크롱). 테슬라 릴스는 릴스 탭에서 고정.
- 릴스를 state 파일로 직접 올릴 때는 감시 작업(pipeline cmd=watch)을 같이 실행.
