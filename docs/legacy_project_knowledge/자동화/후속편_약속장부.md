# 후속편 약속 장부

> 소재 추천(예약 작업·채팅)은 매번 이 장부를 **가장 먼저** 읽고, '열림' 약속이 있을 때만 결과 맨 위 "약속한 후속편" 칸에 올립니다. **열린 약속이 없으면 그 칸을 아예 쓰지 않습니다**(2026.11.02 사용자: "올공 투표지 후속은 왜 자꾸 말하는지 모르겠네").

## 규칙 (10.25 사용자: "후속편은 반응 좋았을 때 하는 게 맞다")
1. **게시물 안에는 후속편을 미리 약속하지 않는다.** 대신 "팔로우하면 다음 소식 바로 받아요"처럼 약속 없는 문구를 쓴다.
2. **반응이 좋았을 때만 후속편을 건다.** 기준: 게시 24시간 안에 비팔로워 비율이 높고 공유가 붙어 팔로워 밖으로 퍼진 게시물. 질문은 "기다리는 사람이 실제로 있나?"
3. **걸 때는 고정 댓글로 건다.** 같은 순간 여기 장부에 한 줄 적는다. 웹 인스타엔 '고정' 메뉴가 없어 고정은 사용자가 앱에서 한다.
4. **기한 = 약속 후 48시간.**
5. **기한이 지나면 자동으로 닫는다.** 새 재료가 없으면 추천에 다시 올리지 않고 장부 상태만 '닫음'으로 바꾼다(2026.11.02 변경: 지난 약속을 매번 다시 꺼내지 않음).
6. 후속편은 '같은 사건 총정리 금지'·'최근 추천 반복 금지' 규칙의 **예외**다.
7. 2편 첫 장·캡션에 "○○ 2편"을 넣는다.
