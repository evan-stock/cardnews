# 예약 작업 "오늘의 카드뉴스 소재 추천 (맥북 크롬)" 새 지시문 (2026.10.28)

> **왜:** 이 작업의 지시문이 10.23 무렵 옛 규칙('와' 영상 5개, '와' 영상 1순위, 유명인 한마디 칸 등)을 통째로 담고 있었고, `소재추천_기준.md`를 읽으라는 줄이 없었다. 그래서 10.27 밤에 바꾼 기준(사회 이슈 중심, 첫 반응 4조건, 반대편에 서기)이 맥북 실행에는 반영되지 않았다. 예비 작업은 기준 문서를 함께 읽어 반영됐다.
> **어떻게:** 맥북의 Claude 앱에서 이 작업을 열고 지시문 전체를 아래 코드 블록 내용으로 바꿔 저장한다(맥북 승인 필요).
> **되돌리기:** 옛 지시문은 `claude/자동화/백업/소재추천_지시문_1024.md` + `claude/자동화/당분간_우선_유럽시위.md`(맨 위 블록) + 아래 4장(운영판 올리기)으로 복원할 수 있다.
> 이제 규칙은 지시문이 아니라 정본 문서만 고치면 맥북·예비 실행 모두에 바로 반영된다.

```

## 1. 규칙은 프로젝트 문서에서 읽는다 (이 지시문에는 규칙을 적지 않는다)

1. claude/자동화/후속편_약속장부.md (매 실행 가장 먼저, 정본 0장)

3. claude/자동화/당분간_우선_유럽시위.md (결과 맨 위 '유럽 시위 새 장면' 칸)

- 사용자 맥북의 크롬(Claude in Chrome)을 먼저 씁니다. 스킬 chrome-browser 가 있으면 먼저 읽고, ToolSearch 로 claude-in-chrome 도구를 한 번에 불러옵니다. 크롬이 안 되면 내장 브라우저(mcp__remote-devices__Claude_Browser__*, 스킬 built-in-browser)를 씁니다. 둘 다 없거나 맥북이 잠자기·연결 끊김이면 맨 위에 밝히고 웹 검색·WebFetch로 진행합니다.
- 새 탭에서 열고 사용자가 열어 둔 탭은 건드리지 않습니다. 읽기만 하고 좋아요·팔로우·댓글·DM·글쓰기·로그인 변경·결제는 하지 않습니다.
- Reddit과 X(트위터)는 열지 않습니다(기사에 인용된 수치·주소는 써도 됩니다).
```
