# 재밌게 퍼지는 게시물 구조 — 참고: @bythepulse '이재용 협상 일화'(2026-11-27, 좋아요 4,761·공유 2,954)

## 왜 재밌나
1. 표지 = 얼굴 두 장 대결 구도. 표정이 결과를 말한다(능글 머스크 vs '쉿' 이재용). 글보다 사진이 먼저 웃김.
2. 말투를 반말로: "무엇을 더 해줄 수 있나" → "너가 뭘 해줄 수 있는데?" + 결과 한 줄("머스크 한 방 먹인 이재용").
3. 한 장 = 한 가지: 위 캡처/사진 1장 → 검은 설명 1줄 → 빨간 큰 펀치라인 1줄. 본문 문단·숫자표 없음.
4. 5장으로 끝: 제안 → 답 → 판 키움 → 같은 답(반복이 웃음 포인트) → "협상 GOAT ㄷㄷ".
5. 방송 그래픽·자막 캡처(JTBC·KNN)로 '진짜 보도'라는 신뢰, 설명은 짧게.
6. 음악 The Godfather, 캡션 첫 줄 "이재용 협상 일화 ㄷㄷ" — 커뮤니티 말투.

## 우리 쪽 차이
- 우리는 장마다 정보 과다(숫자·각주·패널), 저쪽은 장마다 감정 1개.
- 우리 마지막 장 = 입장문, 저쪽 = 박수 한마디.

## 우리 양식으로 옮기기
- 표지: 1번(lay one)에 얼굴 2장 나란히(대결형).
- 안쪽: 4번 single(캡처 + 굵은 두 줄, 아랫줄 노랑 펀치라인).
- 5~6장, 마지막은 한 줄 리액션 + 팔로우.
- 사실 기준 유지: 반말 각색은 표지만, 안쪽 캡처는 원문 그대로, 전언·시점(예: "6월 일화, 카와자 전언")은 각주.
- 양식은 원고 짜기 전에 사용자에게 먼저 묻는다(2026-11-27 사용자 지시).
