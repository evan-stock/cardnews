# 링크 여는 방법 (2026-11-22 사용자 지시)

- 인스타그램·스레드 등 로그인 필요한 링크를 받으면 "볼 수 없다"고 하지 말고 바로 Claude in Chrome(사용자 크롬)으로 연다.
  - WebFetch는 인스타그램에서 robots 차단으로 실패하므로 시도하지 않는다.
  - 순서: ToolSearch로 claude-in-chrome 도구 로드 → navigate → get_page_text(캡션) + screenshot(표지 문구) → 탭 닫기.
- 크롬이 꺼져 있어 실제로 접근이 안 될 때만 캡션·캡처를 요청한다.
