## 목표
@today.worthy(오늘의쓸모) 인스타그램에 카드뉴스와 함께 **릴스**도 만들어 자동 업로드.
- 1순위 방식: 카드 슬라이드(9:16, 장당 2~3초, 천천히 확대) + **한국어 AI 음성 내레이션 + 하단 자막**
- 비용 0원 지향: 무료 TTS(예: edge-tts), 영상 합성은 ffmpeg, 실행은 GitHub Actions(공개 저장소라 무료)
- 배경음악은 저작권 없는 무료 음원만(인스타 앱 인기 음악은 API로 못 넣음)
- 원본 뉴스·틱톡 영상 편집은 다운로드 차단·저작권 신고 위험이 커서 후순위

## 이미 있는 것 (카드뉴스 자동화)
- 저장소: https://github.com/evan-stock/cardnews (공개, main 브랜치)
- 카드 렌더링: `templates/renderer.html`(1080×1350), `cardnews/render.py`(Playwright)
  - 표지 글꼴 Black Han Sans, '강조어' 노란색(따옴표는 화면에 안 보임)
  - 중간 장은 소제목+설명 1~2줄. 단순 가십·동물만 사진만
- 인스타 게시: `cardnews/instagram.py` (graph.instagram.com v25.0, 캐러셀 게시)
  - 릴스는 `media_type=REELS`, `video_url`(공개 주소의 mp4, H.264/AAC, 9:16 권장)로 컨테이너 생성 → 상태 FINISHED 확인 → media_publish
  - 미디어 공개 주소는 raw.githubusercontent.com/evan-stock/cardnews/main/media/... 사용 중
- 텔레그램 승인봇: `cardnews/telegram_bot.py` (미리보기 + ✅/❌)
- GitHub Secrets 등록 완료: ANTHROPIC_API_KEY, TELEGRAM_BOT_TOKEN, TELEGRAM_CHAT_ID, IG_USER_ID, IG_ACCESS_TOKEN (OPENAI_API_KEY·GH_PAT는 없음 → 인스타 토큰은 60일 안에 수동 갱신 필요)

## 운영 방식 (현재)
- **채팅 원고 모드(비용 0, 주력)**: Claude가 채팅에서 소재 조사·문구·사진 선택 → `drafts/current.json`(목록 가능) 푸시 → `manual-draft` 워크플로가 렌더링
  - `mode`: collect(기사 사진 후보 수집, `media/<id>/candidates.jpg`) → render(장마다 지정 사진으로 렌더) → send(텔레그램 전송, `publish_now: true`면 바로 게시)
  - `images`: 후보 번호(press03) 또는 이미지 주소
- **자동 모드**: 11:15/16:15 KST에 Claude API로 소재 조사(회당 약 $0.5) → 텔레그램 승인 → 13:00/18:00 게시. 준비 후 `watch`가 1분마다 승인 확인(GitHub 예약 실행 지연 대비)
- 사용자 선호: 후킹은 반전·숫자·실명 한 방, 노잼 금지 / 엉뚱한 사진 금지(없으면 빼기) / 우파 관점 정치 어그로 소재도 OK(사실은 정확히, 해명 한 줄 포함)
