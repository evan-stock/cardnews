# 개인정보처리방침 (shorts-uploader)

이 앱은 운영자 본인의 유튜브 채널에 쇼츠 영상을 업로드하기 위한 개인용 자동화 도구입니다.

- **수집하는 정보:** 운영자 본인 계정의 OAuth 토큰만 사용합니다. 다른 사용자의 개인정보는 수집하지 않습니다.
- **사용 범위:** YouTube Data API의 동영상 업로드(youtube.upload)와 채널 확인(youtube.readonly) 권한만 사용합니다.
- **보관:** 토큰은 GitHub Actions 암호화 Secrets에만 저장되며 제3자에게 제공하지 않습니다.
- **삭제:** https://myaccount.google.com/permissions 에서 언제든 접근 권한을 해제할 수 있습니다.
- **문의:** 저장소 이슈(https://github.com/evan-stock/cardnews/issues)
