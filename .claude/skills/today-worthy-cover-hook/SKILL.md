# 표지 후킹 제작법 (2026.10.16 사용자 지정 / 2026.10.22 어그로형 27종 추가)

카드뉴스·릴스 표지를 만들 때마다 이 방법을 쓴다. 표지 형식(2~3줄, 줄당 11자 안팎, '작은따옴표' 강조)은 최신 today-worthy-cardnews 스킬을 따른다.
출처: 슬스튜디오 노션 '해외 100만 조회수 릴스 후킹 26가지' (사용자 제공) + 2026.10.22 사용자 요청 어그로형 27종(27~53).

## 역할
조회수 100만 이상 릴스를 분석하는 숏폼 전략가로서, 첫 장만 보고도 끝까지 넘기게 만드는 표지를 쓴다.

## 입력 (매번 주제에 맞게 직접 채운다)
- 🎯 주제: 이번 소재 한 줄 요약
- 👤 타겟: 이 소재를 DM으로 받을 사람
- 🎬 방향: 정보형 / 스토리형 / 자극형 / 감성형 / 브랜딩형 중 1개
사용자가 주면 그대로, 없으면 소재를 보고 정한 뒤 한 줄로 밝힌다.

## 필수 조건
- 한 문장은 짧고 강하게, 초등학생도 아는 단어
- 첫 문장에 주제 + 대상 + 결과
- 숫자·감정·결과·궁금증 적극 활용
- 저장/공유하고 싶은 느낌, 말하듯 자연스럽게
- AI 말투·뻔한 표현 금지
- 결과·감정·호기심 균형, 각 후킹 1~2줄, 전략 이름 표시
- 확인된 사실·숫자만 쓴다 (지어낸 숫자 금지)
- "충격", "충격적", "끝까지 보면" 같은 자극 표현도 템플릿에 맞으면 그대로 쓴다 (2026.10.16 사용자 결정)
- "진짜 이유", "몰랐던 진실", "정체", "소름", "큰일 난다" 같은 어그로 표현을 적극 쓴다 (2026.10.22 사용자 결정)

어그로형 규칙:
- 본문에서 표지가 약속한 이유·진실·반전·결말을 반드시 실제로 보여준다. 약속한 답이 없으면 쓰지 않는다 (낚시 후 실망 = 저장·공유·완독률 하락).
- 이유·진실은 출처로 확인된 것만. 추측을 '진짜 이유'로 단정하지 않는다.
- '90%', '상위 1%', '세계에서 가장', '역대급' 같은 수치·최상급은 근거가 있을 때만. 근거 없으면 '대부분', '손꼽히는'으로 바꾼다.
- 실존 인물·기업에 '숨겼다/속였다/실체' 식 단정은 명예훼손 위험 → 위험도에 꼭 적고, 사실 근거 없으면 '말 안 하는', '잘 안 알려진'으로 순화.
- 35~37 경고형은 건강·안전 소재면 근거(기관·연구) 없이 공포를 키우지 않는다.
- 53은 영상이 실제로 3초 뒤 반전이 있는 릴스에만 쓴다.

## 작업 순서
1. 입력 3가지를 채운다.
2. 소재에 맞는 전략 10개를 골라(겹치지 않게) 후킹 10개를 쓴다. 이 중 최소 5개는 🔥 어그로형(27~53)으로, 어그로형 안에서도 서로 다른 묶음에서 고른다.
3. 출력: `이모지 + 전략명` 다음 줄에 "후킹 문장".
4. 상위 2~3개를 표지 형식(2~3줄, 줄당 11자 안팎, 핵심어 '강조')으로 바꾸고 위험도(명예훼손·혐오·정책·낚시 여부)를 적은 뒤 1개 추천. 본문이 약속을 지킬 수 있으면 어그로형을 우선 추천한다.
5. 추천안을 원고 cover의 t에 넣는다. 사용자가 다른 후보를 고르면 교체.

## 올리기 전 체크리스트
- 첫 문장에 주제 + 대상 + 결과가 있나
- 숫자·감정·결과·궁금증 중 하나 이상 있나
- 초등학생도 바로 아는 단어인가
- 1~2줄, 말하듯 자연스러운가
- 표지만 보고도 끝까지 넘기고 싶은가
- (어그로형) 표지가 약속한 이유·진실·반전이 본문에 실제로 있나
- (어그로형) 수치·최상급 표현에 근거가 있나

## 테스트 팁
같은 소재라도 표지 유형만 바꿔 반응을 비교한다. 성과 확인 때 상위 게시물의 표지 전략 번호를 함께 기록해 우리 계정에서 잘 터지는 유형을 찾는다. 어그로형(27~53)과 기본형(01~26)의 조회·저장·공유 차이를 따로 기록하고, 어그로형 안에서도 묶음별(이유·진실 / 금지·경고 / 반전 / 손해 / 엿보기 / 극단 / 찔리게 / 결말 미루기)로 비교한다.
