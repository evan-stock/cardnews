# 귀여운 동물 쇼츠 제작법 (v1, 2026.10.17)

답변은 항상 한국어로 한다.
저장소: github.com/evan-stock/cardnews (main). 설명서 docs/SHORTS.md. 결정 기록은 프로젝트 문서 claude/쇼츠_파이프라인_결정사항.md.
흐름: 채팅에서 원고(drafts/shorts.json) 작성 → push → shorts.yml이 TTS·합성 → 텔레그램 미리보기 [✅ 업로드] → 유튜브 API 업로드(채널 JJ, 채널명 변경 예정).

## 채널 정체성 (확정)
- 귀여운·웃긴·신기한 **동물** 영상만 다룬다. 다른 장르를 섞지 않는다.
- 필재(중년 남성) TTS가 진지한 다큐 톤으로 해설한다. 진지할수록 귀여움과 대비되어 웃긴다. 예: "이 수컷은 오늘, 생애 첫 패배를 맛보게 됩니다."
- 수익: 영상 수익 + 반려용품 쇼핑 제휴(영상에 실제 나오는 물건과 같은 종류만).

## 성공 양식
1. **길이 15~25초**, 4~5장면. 반복 시청을 노린다.
2. **0초에 사건(가장 귀엽거나 웃긴 장면)**. 도입 설명 없이 바로 시작.
3. **제목 2줄**(줄당 10~12자): 1줄 상황, 2줄 반전·결말 예고. 공식:
   - "~하는 이유" / "~의 최후" / "~했더니" / "~의 반응" / "상상 vs 현실"
   - 동물 캐릭터화: "금쪽이 시바견", "구역 서열 1위 고양이"
   - 끝에 ㅋㅋ/ㄷㄷ/? 로 감정을 붙인다. 강조 단어는 '작은따옴표'(노랑).
4. **하루 1개 안팎**, 같은 문장 틀 반복 금지(진정성 없는 콘텐츠 정책).
5. 반응 좋은 동물·상황은 시리즈로("구역 서열 시리즈", 랭킹 1~5위).

## 대본 공식 (필재 다큐 톤)
1. 장면1(0~3초): 사건 + 훅 한 문장. "이 햄스터, 지금 안약을 맞고 있습니다."
2. 장면2~3: 상황 → 반전. 다큐처럼 관찰하듯 말한다.
3. 장면4: **동물 행동 사실 한 줄**(웹에서 확인한 것만). 해설 가치 = 정책 방어.
4. 마지막: 한 줄 결론 + 공유 유도("이런 친구 하나씩 있죠"). 구독 요청은 짧게.
- 어미 ~습니다/~입니다. 한 문장 15~25자. 숫자는 읽는 대로.

## 디자인 A안 (확정, config shorts.layout=band)
- 위 검정 띠 480px, 2줄 제목(1줄 노랑, 2줄 흰). 띠 아래 영상 꽉 채움.
- **안전영역(2026.11.07)**: 쇼츠 목록은 위아래 약 140px을 자르고 맨 위를 '새 동영상' 배지·⋯가 덮는다. 제목 글자는 y 260px 아래에서 시작해 띠 아래쪽에 붙인다(1줄 약 260~360, 2줄 360~460). 0~260px엔 글자 금지. 아래 자막·원작자·마스코트는 y 1520 이하. 렌더 확인 때 위아래 140px 자른 2:3 미리보기로 제목 1줄이 다 보이는지 본다.
- 가로 영상은 `video.x`(0~1)로 동물이 있는 쪽을 크롭. 너무 잘리면 `"fit":"fit"`.
- 빨간 태그(hook.tag, 선택), 자막 68% 높이, 왼쪽 아래 원작자 표기(photo_credits 또는 credit), 오른쪽 아래 마스코트(shorts.mascot, 파일 준비되면 설정).

## 정책 (수익화 지키기)
- 해설 없는 클립 모음은 '재사용 콘텐츠'로 수익화 불가. 틀만 바꾼 대량 생산은 '진정성 없는 콘텐츠'(2025.7.15).
- 그래서: 영상마다 직접 쓴 대본, 자르기·순서 재구성 편집, 출처 표기(화면+설명란), 워터마크 제거 금지.
- 저작권 클레임은 별개다. 가능하면 원작자 허락·라이선스 있는 소스를 쓴다.
- 2027.2.1부터 쇼츠 YPP 신규 기준 90일 2,000만 회로 상향 예정 → 쇼핑 수익 비중을 일찍 키운다.
- AI 장면은 label "AI 참고 이미지" → 업로드 때 합성 콘텐츠 자동 신고.

## 쿠팡 제휴
- 쇼츠 설명란·댓글 링크는 클릭되지 않는다.
- **유튜브 쇼핑 제휴**: 쿠팡 파트너사, 2026.3.30부터 YPP + 구독자 500명, 쿠팡 태그 수수료 6.7%(변동 가능, 스튜디오 → 수익 창출 → 쇼핑에서 확인). 태그는 업로드 후 사용자가 앱·스튜디오에서 직접 단다.
- 그 전: 채널 프로필 첫 링크에 상품 모음, 설명란에 "영상 속 제품은 프로필 링크에서" + "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
- 소재 고를 때 연결할 상품이 있는지도 표시한다(장난감, 자동 급식기, 캣타워, 목욕용품 등). 무관한 상품 도배 금지.

## 작업 순서
1. **소재 추천**(4~6개): 틱톡·유튜브·레딧(r/aww, r/AnimalsBeingDerps 류)·X의 최근 동물 바이럴. 각각 제목 시안 2줄, 0초 장면, 연결 상품, 원본 주소·원작자.
2. **영상 받기**: drafts/video.json({"id","urls","frames":2}) push → fetch-video → media/<id>/video/. 프레임 모음으로 핵심 장면 시각·크롭 위치 결정.
3. **원고**: drafts/shorts.json(mode=render로 먼저 시험). hook.t 2줄, scenes[].say, video{src,start,x}, photo_credits, yt{title,description,tags}.
4. **확인**: 렌더 결과 프레임을 직접 보고 제목 넘침·크롭·자막 싱크 확인.
5. **업로드**: mode=send → 텔레그램 [✅ 업로드] → 유튜브. 예약은 publish_at + approved.

## TTS
- 기본 필재(tc_68257f68bc6e3c161ab5078d), emotion smart, tempo 1.1. 바꿔달라 하면 config.yaml shorts.tts.voice_id, 한 영상만이면 원고 voice.
- 목소리 검색: shorts 워크플로 cmd=voices, q=이름. 타입캐스트 무료 월 3만 자, 넘으면 Edge TTS 자동 대체.

## 하지 않는 것
- 동물 학대·다친 동물을 웃음거리로 쓰기, 해설 없는 클립 모음, 같은 대본 틀 반복, 워터마크 제거, 확인 안 된 동물 상식, 무관한 상품 태그.
