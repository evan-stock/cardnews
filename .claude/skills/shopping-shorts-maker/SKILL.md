# 쇼핑 쇼츠 제작법 (v1.1, 2026.10.17)

답변은 항상 한국어로 한다. '오늘의 털뭉치'(동물 채널, youtube-shorts-maker 스킬)와 같은 파이프라인을 쓴다. 다른 점은 소재·대본·목소리·업로드 채널·상품 태그다.
저장소: github.com/evan-stock/cardnews (main). 설명서 docs/SHORTS.md. 결정 기록: 프로젝트 문서 claude/쇼츠_파이프라인_결정사항.md.

## 채널 콘셉트
- 먹거리·생활용품·유통 브랜드 이야기(코스트코, 다이소, 편의점, 프랜차이즈, 화제 신제품). **영상의 주인공 = 태그할 상품**이라 클릭이 자연스럽다.
- **기본 목소리: 진우(타입캐스트, 남 20대 밝은 톤, tc_632293f759d649937b97f323)** — 2026.10.17 사용자 지정. config.yaml shorts.channels.shop.voice 에 들어 있어 원고에 `yt.channel: "shop"` 만 넣으면 자동 적용. 한 영상만 바꾸려면 원고 voice.
- 수익 구조: 쇼핑 태그 수익이 주력, 시청 수익은 보조. 1차 목표는 수익화 승인(YPP).
- 채널명·디자인은 사용자가 정한다(정하면 이 절을 고친다).

## 벤치마크: 맛있는 친구들 (@yummyknow-x1x, 2026.10.17 분석)
- 구독자 4.15만, 쇼츠 84개. "한국 코스트코가 억울했던 이유" 1,048만회, "영업기밀 털린 맘스터치" 545만회, "비요뜨를 제쳐버린 다이소" 484만회, "노브랜드가 억울했던 이유" 386만회.
- 화면: 커뮤니티 게시글 카드형(위 채널 로고 띠, 게시판 이름·날짜, 검정 제목, 가운데 영상, 흰 배경). 왼쪽 아래 상품 태그 "2개 제품" + "수수료 지급" 표시(유튜브 쇼핑 제휴).
- 제목 공식: "~가 억울했던 이유", "~가 당황했던 이유", "영업기밀 유출된 ~", "~ 근황", "~를 제쳐버린 ~", "결국 팀킬해버린 ~", "한국인들이 기강 잡아버린 ~". 브랜드명을 제목 앞에, 감정(억울·당황·난리)을 뒤에.
- 참고 이슈 채널: 평양냉면("부캉이 보러 '부산에 간' 일본인이 발견한 것?ㅋㅋㅋ") — 밝은 20대 남성 TTS 톤.

## 대본 공식 (20~30초, 5~6장면)
1. 장면1: 상품이 가장 맛있어 보이거나 놀라운 장면 + 훅("이 과자, 출시 일주일 만에 품절됐습니다").
2. 장면2~4: 배경 → 반전 → 숫자(가격·판매량·출시일). **숫자·사실은 기사·공식 발표에서 확인한 것만**.
3. 장면5: 한 줄 결론 + 궁금증("여러분은 먹어보셨나요?").
- 진우 톤에 맞게 밝고 리듬감 있게. 어미 ~습니다/~입니다 기본, 감탄은 짧게. 브랜드 비방·허위 사실·과장 효능(건강·다이어트) 금지. 논란은 회사 해명도 한 줄.

## 영상 소스
- 우선: 브랜드 공식 영상·SNS, 상품 리뷰 틱톡(원작자 표기), 뉴스 보도 영상. 방송 예능 클립은 저작권 신고 위험이 커서 피한다.
- 영상이 모자라면 상품 사진(scenes[].img, 천천히 확대) 또는 Higgsfield AI 장면(label "AI 참고 이미지" → 합성 콘텐츠 자동 신고).
- 짧은 원본은 장면별로 잘라 앞으로+거꾸로 이어 붙여(부메랑) 길이를 늘린다.
- 해설 없는 클립 모음은 '재사용 콘텐츠'로 수익화 불가. 매 영상 직접 쓴 대본 필수. 같은 문장 틀 반복 금지(진정성 없는 콘텐츠, 2025.7.15).

## 상품 태그·쿠팡
- 쇼츠 설명란·댓글 링크는 클릭되지 않는다.
- **유튜브 쇼핑 제휴**: 쿠팡 파트너사. 2026.3.30부터 YPP + 구독자 500명. 쿠팡 태그 수수료 6.7%(변동 가능, 스튜디오 → 수익 창출 → 쇼핑에서 확인). 태그는 업로드 후 사용자가 앱·스튜디오에서 직접 단다(API 미지원) → 매 영상 마무리에 **태그할 상품명을 정확히** 알려준다.
- 자격 전: 채널 프로필 첫 링크에 상품 모음, 설명란에 "영상 속 제품은 프로필 링크에서" + "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
- 영상에 실제 나오는 상품만 태그. 무관한 상품 도배 금지.
- 소재 고를 때 "쿠팡에서 그 상품을 팔고 있는가"를 먼저 확인한다(안 파는 상품은 수익 연결 불가).
- 참고 계산: 2만 원 상품 약 100개/월 판매 ≈ 월 100달러.

## 파이프라인 사용법 (기존과 같음 + 채널 지정)
- 원고 drafts/shorts.json: 기존 형식 + `yt.channel: "shop"` (Secrets `YT_REFRESH_TOKEN_SHOP` 으로 업로드, 진우 목소리 자동). 채널 디자인은 config shorts.channels.shop.style 또는 원고 `style`(예: {"mascot":"assets/shop_mascot.png"}).
- 내레이션 없는 영상도 가능: `"narration": false` + 장면 `dur` + `bgm`(assets/bgm/, 유튜브 오디오 보관함 곡).
- 영상 받기: drafts/video.json {"id","frames":0,"format":"bv*[height<=1920]+ba/b","urls"} push → fetch-video → media/<id>/video/v1.mp4. 프레임 모음(ffmpeg fps=1 tile)을 Read 로 보고 장면 시각·크롭 y 결정.
- 미리 확인: 원고 복사본에 mode render + voice {"engine":"silent"} 로 로컬 렌더 → 프레임 확인 → 로컬 결과물 지우기.
- 보내기: mode send push → shorts 워크플로가 타입캐스트로 만들어 텔레그램 [✅ 업로드] → 승인 시 업로드. **서버가 만든 short.mp4 를 반드시 프레임으로 직접 확인**한 뒤 사용자에게 보낸다.
- 원본 캡션은 scenes[].video.blur=[x,y,w,h](원본 좌표). 피사체 위면 흐리지 말고 y 로 피한다.
- 업로드 할당량: Google Cloud 프로젝트 하나당 하루 6건(두 채널 합계). 넘치면 프로젝트를 하나 더 만든다. 타입캐스트 무료 월 3만 자도 두 채널 합계(넘으면 Edge TTS 자동 대체).

## 새 채널 연결 (처음 한 번)
1. 사용자가 유튜브에서 브랜드 채널을 만든다. '고급 기능 이용하기' 창이 뜨면 6초 영상 인증(몇 시간)이 필요하다.
2. 업로드 동의(내장 브라우저, 기존 OAuth 앱 shorts-uploader1 그대로): `https://accounts.google.com/o/oauth2/v2/auth?client_id=<YT_CLIENT_ID>&redirect_uri=http%3A%2F%2F127.0.0.1%3A8765&response_type=code&scope=https%3A%2F%2Fwww.googleapis.com%2Fauth%2Fyoutube.upload%20https%3A%2F%2Fwww.googleapis.com%2Fauth%2Fyoutube.readonly&access_type=offline&prompt=consent%20select_account` → 계정 선택에서 **새 브랜드 채널**을 고르게 한다(어느 채널인지 사용자에게 확인) → '확인되지 않은 앱'은 고급 → 이동 → 권한 '모두 선택' → 계속(권한 부여는 사용자 동의를 받고 누른다).
3. 페이지가 127.0.0.1 로 넘어가며 멈추는 건 정상. read_network_requests 에서 `batchexecute?rpcids=qu7pO` 응답 본문의 `code=` 값을 읽고, 같은 탭에서 javascript fetch 로 https://oauth2.googleapis.com/token 에 교환한다(컨테이너는 구글 토큰 서버에 못 붙는다). 코드는 약 10분 만에 만료된다. access_token 으로 channels?mine=true 를 불러 채널 이름을 확인한다.
4. refresh token 을 사용자에게 보여주고 GitHub Secrets `YT_REFRESH_TOKEN_SHOP` 에 직접 넣게 한다(세션은 Secrets API 접근 불가, 토큰을 웹 입력란에 대신 입력하지 않는다). 임시 사본은 지운다.
5. 확인: Actions → shorts → cmd yt-check, q shop → state/shorts_log.txt 에 채널 이름.

## 겪었던 문제와 해법
- 서버에 Black 폰트가 없어 글자가 깨알처럼 나옴 → fonts-noto-cjk-extra 설치 + Bold 대체로 해결. 로컬 시험본만 보고 넘기지 말 것.
- 자막은 116px, 덩어리 8자(폰에서 82px는 작다는 피드백).
- publish_now 는 '승인되면 바로 공개'일 뿐 승인을 대신하지 않는다. 채팅에서 사용자가 올리라고 하면 state/posts/<id>.json status 를 approved 로 바꿔 push.
- 텔레그램 승인이 안 먹으면 승인 감시(pipeline watch)가 멈춘 것 → 진행 중 cardnews 실행을 cancel 하고 watch 를 다시 dispatch.
- 화면 태그('● 실제 영상')는 기본 꺼짐(config shorts.tag=false).
- 유튜브 오디오 보관함 곡 받기: 내장 브라우저는 파일 다운로드가 안 되고 기기 쉘도 googlevideo 가 막힘 → 스튜디오 페이지에서 fetch 를 가로채 get_tracks 응답의 downloadAudioUrl(약 1시간 유효)을 모아 drafts/video.json urls 로 fetch-video 워크플로가 받게 한 뒤 assets/bgm/ 로 옮긴다. 다운로드·약관 동의는 사용자 허락 후.

## 하지 않는 것
- 허위·과장 상품 설명, 브랜드 비방, 확인 안 된 숫자, 방송 클립 도용, 워터마크 제거, 무관한 상품 태그, 사용자 승인 없는 업로드, 상품 구매·결제.
