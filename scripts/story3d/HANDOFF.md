## 1화: 「라면 국물까지 다 마시면 몸에서 생기는 일」
내레이션(제미나이 TTS, 목소리 Fenrir, 1.08배속·무음 정리 후 37.3초) → `audio/vo.wav`, 효과음까지 섞은 것 → `audio/mix_full.wav`

1. 밤 열한 시. 이 남자는 라면 국물을 마지막 한 방울까지 마십니다.
2. 이 봉지 하나에 나트륨 천칠백구십 밀리그램. 하루 권장량 이천의 구십 퍼센트.
3. 십 분 뒤, 갑자기 목이 탑니다.
4. 이유는 이겁니다. 피가 짜지면, 뇌가 경보를 울립니다.
5. 물을 더 마시게 하고, 콩팥에는 물을 내보내지 말라고 명령하죠. 짠 피를 묽히려고, 물을 붙잡아 두는 겁니다.
6. 그렇게 붙잡힌 물 때문에, 다음 날 아침 얼굴이 이렇게 됩니다.
7. 콩팥은 남은 소금을 다 내보낼 때까지 일합니다.
8. 그럼 국물만 남기면 될까요? 한 연구에서, 라면 나트륨의 절반은 이미 면에 배어 있었습니다.
9. 국물을 다 남겨도, 줄어드는 건 절반. 그래도 절반이 어디예요. 오늘은 남기세요.

장면 순서(3D 버전 `full.html`의 SEG/SH 참고): 원룸에서 국물 마시기 → 봉지 성분표 숫자 올라감 → 목마름 → 뇌 관제실 경보 → 뇌가 명령 → 콩팥 공장 밸브 잠금 → 피 비커(짠 피 묽히기) → 아침 거울 부은 얼굴 → 밤새 일하는 콩팥 → 면 단면(나트륨 절반) → 마무리.
화면 출처 문구: "※ 농심 신라면 120g 영양정보 · WHO 성인 나트륨 권고 2,000mg 미만", "※ 대한지역사회영양학회지(2014): 라면 1개 나트륨 중 국물 약 49%, 면 약 51%".

## 렌더링 방법
- 페이지는 `window.renderFrame(t)`(초 단위)를 정의하고, 준비되면 `window.ready = true`.
- `node frames.js v2d/man.html out 30 4` → `out/0000.png…` (720×1280), 그다음
  `ffmpeg -framerate 30 -i out/%04d.png -i audio/mix_full.wav -c:v libx264 -pix_fmt yuv420p -crf 18 -shortest ep1.mp4`
- 필요: node + `npm i playwright` + `npx playwright install chromium`, ffmpeg.

## 운영 원칙(요약)
- 같은 틀의 AI 양산형 영상을 공장식으로 찍지 않는다. 화마다 원본·대본·음성·사용 자료 출처를 폴더로 보관한다.
- 사실 수치는 출처를 확인하고 화면에 출처를 적는다.
- 사용자를 '형'이라고 부르지 않는다. 쉽게 설명하고, 사용자가 직접 해야 하는 일(로그인·결제·권한)만 부탁한다.

## 그림 다듬는 방법: 드림 루프(dream-loop 방식, github.com/achimala/dream-loop 참고)
목표 그림에 가까워질 때까지 아래를 반복한다. 설치할 건 없고 작업 순서다.
1. 목표 그림(`assets/story3d/targets/*.png`)을 기준으로 정한다.
2. 코드로 그리고 렌더링한다(`node frames.js 페이지 out 30 0 0` 같은 식으로 한 장만 뽑아도 됨).
3. 목표 그림과 결과를 나란히 붙인 비교 이미지를 만든다.
4. **목표를 만든 적 없는 별도 에이전트(서브에이전트)**에게 두 그림을 보여주고, 다른 점 상위 8개와 닮은 정도 점수(0~10)를 받는다. 직접 고친 사람이 스스로 채점하지 않는 게 핵심.
5. 지적대로 고치고 다시 2번으로. 점수가 8 이상이거나 더 나아지지 않으면 멈추고 사용자에게 비교 이미지를 보여준다.
